# A股量化页面布局实施说明

参考同目录的 `index.html`。这是独立 HTML demo，双击即可打开，无需安装依赖。所有数据和操作为演示，未连接行情、账户持久化、模型或交易服务。现有 `app.py` 和业务服务未由本次布局任务修改。

## 目标：减少操作，分清功能

采用两个区域：左侧约 236px 的模式与参数栏，右侧结果区。保留现有浅色工作台与深色决策横幅，缩小标题、去除重复英文标题与装饰 emoji。桌面结果区最大宽度 1260px；小屏模式入口横排，参数两列，正文纵向堆叠，清单独立横向滚动。

四个入口为「今日调仓」「攻守轮动」「因子实验室」「AI 多因子」。模式名不附带长说明，不继续用多行 radio。左侧只展示当前模式需要的参数。切换模式应保留各自参数与最近结果，避免重复填写；demo 为简洁展示会恢复默认值，正式实现需用 session_state 保留。

## 今日调仓：按阅读顺序排列

1. 页面标题与「刷新行情」。平台全名不再占用正文第一屏。
2. 深色决策横幅：操作结论、原因、信号状态、执行窗口和行情时间。盘中预览与尾盘确认必须显式区分。
3. 一行账户状态：总资产、持仓状态、可用现金。模拟账户选择放左侧，不塞入指标标题。
4. 两列内容：左侧为执行清单和执行按钮，右侧为进攻/防守行情。宽度不足时上下排列。
5. 单个折叠详情：历史调仓记录、动量规则、行情时效与数据质量门禁。展开后可用现有表格展示全部字段。

清单主列使用中文：操作/标的、数量（股）、参考价、状态；金额显示在汇总区。多笔委托时增加每笔预计金额列，汇总仍展示合计。symbol 放在标的名称下方。空清单显示「当前无需调仓，保持现有持仓」，不展示不可执行的空表。

执行按钮紧邻清单，避免固定悬浮遮挡内容。盘中置灰并说明时间窗；窗口内且后端校验通过时才启用。成功后刷新持仓、现金、清单和流水，防止重复提交。委托顺序与金额、费用计算完全沿用服务结果，不从 HTML 数值反推业务规则。

## 简化操作要求

- 不增加弹窗、多步骤向导、嵌套菜单和额外确认流程。
- 常用参数直接改；低频参数用原生折叠区。
- 回测模式只留一个运行入口，结果在当前页面出现。
- 当前业务已有自动模拟调仓开关，放到「账户与自动调仓」中，保留原有默认值与执行语义；不要因布局改造引入新自动操作。
- 刷新时展示短暂加载状态；异常就地说明原因并允许重试。
- 日期、佣金、账户名称保留原业务校验；失败时显示在对应字段附近。
- 使用中国市场红涨绿跌，同时提供正负号；空仓和零收益显示中性色。
- 不假造回测表现：demo 的研究结果为「—」，正式版接入现有报告。

## 给实施 AI 的指令

请参考 `docs/layout-demo/index.html` 调整当前 Streamlit `app.py` 的布局，复用现有 `services/rebalance_service.py`、策略和报告逻辑。先检查工作区已有修改，避免覆盖。此次范围是页面分区、文案、样式和组件位置，不改变策略计算、费用、时间窗、数据质量门禁或账户持久化。

优先采用 Streamlit 原生组件：sidebar 管理四模式和参数；使用 segmented_control 或简短导航按钮替代长 radio；columns 展示账户与内容；expander 管理低频设置和详情；dataframe 使用中文列名与格式配置。适量 CSS 控制标题、间距、颜色即可。若 Streamlit 无法精确还原 HTML，以阅读顺序、功能分区和简单操作为准，不为像素还原重写业务前端。

保留原报告的全部指标（累计/年化收益、基准、超额收益、最大回撤、夏普/卡玛）和四类分析结果。demo 为简化概念只展示三个占位指标，不代表删除其他指标。保留逐笔成交、周期收益、持仓和复盘能力；详情可折叠或使用同级标签。

## 验收

- 四个模式可直接进入，各自仅展示相关参数，切换后参数不丢失。
- 今日页面首屏可以读到决策与主要执行清单，标题不挤占页面。
- 盘中禁止执行；尾盘依据后端真实条件启用；自动模拟调仓及重复提交保护仍有效。
- 空仓、已有持仓、无需调仓、多笔委托、行情延迟、运行错误都有清晰反馈。
- 研究页一次点击运行，当前页展示完整现有报告。
- 桌面、小屏和键盘操作可用，长表格不撑破页面。
