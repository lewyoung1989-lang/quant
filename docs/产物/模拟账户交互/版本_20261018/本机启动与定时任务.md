# 本机启动与定时任务

## 使用

在 Finder 中双击项目根目录的 [启动量化研究台.command](../../../../启动量化研究台.command)。脚本检查现有 Python 环境，启动或复用 8501 网页服务，启动模拟账户后台进程，并打开 http://127.0.0.1:8501/ 。终端提示完成后可关闭终端；再次双击不会重复启动网页服务。启动失败时窗口保留错误提示。

依赖现有 `.venv`，不自动下载或安装依赖。项目移动位置后请在新位置运行 `.venv/bin/python scripts/start_system.py --install-login` 更新后台路径，必要时重建虚拟环境。网页服务日志为 `data/user_profile/web.log`。

## 已确认的本机运行方案

用户确认交易时段开机，采用 macOS 登录后台任务；已安装 `~/Library/LaunchAgents/com.quant.daily-pipeline.plist`。登录后自动运行数据和策略任务，网页通过双击脚本打开。仅开机未登录、关机或睡眠期间不运行，恢复后补齐缺失数据；不补做错过的模拟交易。

- 每 60 秒检查一次；同一交易日已成功的数据不重复下载。
- 交易日 16:30 起更新当天完整日线；此前补齐上一交易日。周末使用最近交易日。
- 数据包含账户涉及的 ETF、沪深 300、红利低波估值和国债利率。失败保留旧快照，15 分钟后重试；数据未齐暂停模拟执行。
- 数据就绪后生成各账户策略预览；交易日 09:15—15:05 每 5 分钟刷新，参数或数据日期改变也重新生成。
- 预览使用现有模拟策略计算逻辑。执行前重新验证实时行情、交易日历、账户版本及持仓；不将预览直接当成交指令。研究回测的次日收盘模型与模拟账户尾盘实时模型仍有区别。
- 手动账户需用户确认；开启自动的账户仅在交易日 14:45—14:55 尝试模拟调仓。不会连接券商下单。
- 年度交易日历缺失时停止执行，需维护 `configs/trading_calendar_年份.json`。

任务状态位于模拟账户页面底部“查看任务状态”。持久化状态和信号记录位于原 `data/user_profile/simulation.sqlite3`；后台日志为 `daily_pipeline.log` 和 `daily_pipeline_error.log`，均在同一目录。日志和信号历史暂未配置自动清理。

## 暂停和卸载

暂停每日数据与信号任务：

```sh
launchctl bootout gui/$(id -u)/com.quant.daily-pipeline
```

永久取消登录任务，再删除 `~/Library/LaunchAgents/com.quant.daily-pipeline.plist`。再次双击启动脚本会重新安装任务。取消数据任务不等于取消账户自动调仓；如需停止自动调仓，请在账户设置关闭“尾盘自动”。
