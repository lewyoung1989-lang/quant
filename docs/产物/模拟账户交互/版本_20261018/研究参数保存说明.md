# 研究参数自动保存 · 2026-10-18

用户要求刷新后保留之前选择的参数。本地已实现各研究策略独立保存：标的、仓位、阈值、日期区间、费率、因子表达式与选项等控件修改后自动写入 SQLite；刷新、新会话或重新打开时恢复。最后访问的工作模式也保存。不同策略、不同可选范围独立记录，避免 ETF 与股票 Top-K 互相覆盖。

研究参数数据库：`data/user_profile/research_preferences.sqlite3`；模拟账户数据库仍为 `data/user_profile/simulation.sqlite3`。模拟账户本来就保存配置、资金、持仓、成交和操作记录。两者均位于本机，不是云端同步；支持 QUANT_PROFILE_DIR 隔离测试与自定义目录。

45 项测试通过。新增测试通过全新 Streamlit 会话恢复仓位、标的、日期区间、表达式，并验证跨策略隔离。页面控件增加自动保存提示。此前尚未被保存的临时会话参数无法从已关闭的浏览器恢复，修改后开始持久保存。
