## 判断与建议

有依据把 25/35 留作候选，不足以证明它未来优于 20/40。全段历史已用于观察及选参数，两组及参数网格都属于样本内检查；未做独立样本外显著性检验，无法量化“过拟合概率”。建议固定这两组分别前向模拟，提前约定评估期限和收益、回撤、换手指标，避免随结果不断改阈值。此次没有改动应用默认参数或真实模拟账户。
