# 成交时点设置与复测 · 2026-10-18

用户确认界面仅提供两种模式，位于“回测参数 · 标的、周期与交易设置 → 成交时点”。选择后自动重新计算，选择保存到本地，刷新恢复。

- **当日收盘成交（理想化对照）**：使用当天最终收盘信号，按当天收盘参考价成交。信号日与模拟成交日相同，包含前视偏差，不能当作集合竞价可实现收益。
- **次日开盘成交**：使用上一交易日信号，在下一交易日开盘参考价成交。原持仓承担隔夜跳空，成交后新持仓承担开盘至收盘涨跌。

界面首次默认当日收盘对照。三种研究策略共用该设置，图表、费用、账单和 CSV 同步；CSV 包含成交模式，文件名区分模式。模拟账户执行规则未修改。旧引擎默认的前日信号次日收盘模式保留供兼容，界面不再列出。

两种模式均以首个回测日期的现金净值作为锚点，从第二个日期开始撮合；股债两腿分别计费、目标不变持有原份额，使用可分割份额，不模拟限价成交概率或集合竞价未成交。估值数据历史发布时间未独立审计。
