# 红利策略现金防守修复

2026-10-18 用户要求移除防守国债，直接持有现金，同时修复次日开盘模式的缺失价格报错。已本地实现，未推送或部署。

## 修改与使用

红利研究页固定显示“现金（不计息）”，撤销未接入计算的国债 / 年化 1.8% 现金管理选项。红利未投资部分持有现金，无利息、无现金交易费；仅红利 ETF 买卖计费。此页三个研究策略共用现金防守，不改其他攻守轮动策略。ERP 指标仍使用国债收益率作为估值输入，这不代表持有国债。

两种成交模式继续可用：当日信号当日收盘（理想化）与前日信号次日开盘。开盘模式无需国债开盘价。页面旧缓存缺少 bond_open 字段，原缓存函数又无文件版本参数，因此复用了旧数据；现已增加行情文件修改时间及现金模型版本作为缓存键。文件更新或模型切换会重新加载。

CSV 记录成交模式和防守资产。历史国债模型通过内部显式参数保留供回归测试，页面与默认回测均采用现金。刷新页面即可使用，保留用户其他参数。

## 验证

56 项自动化测试通过，新增现金防守无价格依赖、现金不生息、只收红利腿费用、开盘与收盘资金守恒等检查。桌面 1512px 与手机 390px 切换两种模式、刷新恢复并检查页面无异常；最后恢复次日开盘选项。
