# 账户与策略入口简化 · 2026-10-17

用户反馈模拟账户与策略库功能重复，要求整个交互清晰、操作简便。本轮已本地实施，待用户复核，未远程部署。

## 现在的操作路径

1. 在「模拟账户」点击「新增模拟账户」。
2. 填写名称和资金，直接选择策略、调整参数，默认手动执行。
3. 创建后查看持仓与调仓清单，符合执行条件时执行。
4. 后续通过「资金管理」出入金，通过「策略与设置」查看配置并修改或暂停账户。
5. 需要历史分析时进入「策略研究与回测」。

移除一级「策略库」及其重复创建流程，策略介绍整合在选择卡中；账户标题栏移除重复的设置按钮，保留「策略与设置」页签和策略观察区的就近修改入口。交易佣金折叠显示，支持展开修改，校验错误会展开对应区域。两种策略的参数仍可直接设置，切换策略保留未提交参数。
