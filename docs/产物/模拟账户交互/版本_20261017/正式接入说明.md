# 模拟账户工作区 · 本地业务接入

> 本文件记录首次业务接入。用户反馈与 Demo 差距较大后，界面已改为直接复用 Demo 前端；当前界面实现与新增验证以[界面还原说明](界面还原说明.md)为准。下文原生控件及 32 项测试等描述保留为首次接入历史，数据与执行口径仍适用。

2026-10-17（Asia/Shanghai），按用户「可以的，按照这个做吧」的确认，将本版本交互 Demo 接入现有 Streamlit 应用。新账户默认手动执行，可主动开启尾盘自动模拟调仓。本次完成本地实现与验证，没有部署远程服务或连接券商。

## 使用入口

运行 `.venv/bin/streamlit run app.py`，打开 [本地工作区](http://127.0.0.1:8501)，在左侧选择「模拟账户」。

1. 点击「新增模拟账户」，填写名称、初始金额、策略与参数，创建后自动选中新账户。
2. 在「账户总览」核对持仓、策略目标、待执行委托、费用与剩余现金。执行条件成立时点击「执行模拟调仓」。
3. 「资金管理」进行模拟出入金；「账户设置」修改名称、策略、参数、佣金与自动开关。策略变更保留持仓，由下一次执行完成调整。
4. 在五个标签中查看总览、成交、资金流水、运行记录与设置。成交记录可按方向筛选并导出 CSV。
5. 暂停账户后，手动与自动执行都会停止；现金、持仓和配置保留。

桌面使用三列账户卡片、左右分区工作台与右侧配置面板；手机使用可横向浏览的账户卡片、单列资产布局和优先展示的调仓区。研究与回测入口继续保留。

策略通过显式 `strategy_type` 绑定，不根据账户名称推断。支持攻守动量轮动、红利低波 ERP；因子与模型仍属于原有研究能力。

新 ERP 账户默认分位阈值 20% / 80%，三档仓位 50% / 75% / 100%；迁入的 ERP 账户保留旧业务的 20% / 35% 阈值。轮动的三个进攻条件沿用原逻辑，观察周期支持 5–120 个交易日。已有账户的自动开关沿用原值，新建账户默认关闭。

## 资金与执行口径

- 资金、持仓、成交和执行回执在同一事务中更新；出错整批回滚，重复提交不会重复成交。
- 出入金同时调整现金和净投入，不计入累计收益金额；出金不得超过可用现金。收益率仍是相对净投入的简单比例，不是时间加权或资金加权收益率。
- 手动和自动执行均限交易日 14:45–14:55（截至 14:55:59）。节假日、周末、未知年份日历、暂停账户都会阻止执行。
- 执行前重新取得行情并重算清单；报价同日且不超过 90 秒，不能明显来自未来，各标的时间差不能超过 15 秒。历史指标须覆盖前一交易日。
- 账户版本、价格、数量或目标变化后，手动执行要求刷新并重新核对。写入事务内再次检查真实时间与报价时效。
- 权益 ETF 按 T+1 维护可卖份额，国债 ETF 按 T+0；买入按 100 份取整，费用计入资金。卖出受限时整个买卖批次不执行。
- 新账户默认单边佣金万 1，旧账户迁移为万 3，可在设置中修改。ETF 不收印花税；不设最低佣金。当前按参考价整批模拟成交，未模拟盘口、涨跌停队列、滑点或部分成交。
- 缺少持仓报价时资产显示「—」，不补造价格。休市报价可供查看，但不能用于执行。

## 数据保存、迁移与恢复

新数据保存在忽略跟踪的 `data/user_profile/simulation.sqlite3`。首次进入自动事务导入原 `simulated_accounts.json`、`simulated_trades.json`，原 JSON 文件保留；迁入持仓缺少买入日期时保守按导入日建立可卖批次。迁移标记确保多次进入不重复导入。旧流水没有费用字段时显示为空。

当前本地 3 个旧账户已迁入，现金与自动开关核对一致；本轮未向用户账户新增模拟成交。迁移前原系统未记录完整出入金历史，迁入净投入沿用旧初始资金，不补造历史流水。

迁入后以 SQLite 为数据源，旧 JSON 是迁入时的留存材料，不会同步新变动。备份应停下应用与自动进程后复制整个 `data/user_profile/`；恢复前保留现有目录副本，再替换备份。不要删除 SQLite 来「刷新」账户，这会丢失迁入后的新操作。

测试或独立环境可设置 `QUANT_PROFILE_DIR=/绝对路径`。`QUANT_DISABLE_WORKER=1` 可关闭应用自动拉起后台进程；这用于测试环境。

## 自动模拟的运行方式

启用某个运行中账户的「尾盘自动模拟调仓」后，应用会启动独立本地检查进程；默认每 20 秒检查一次，关闭浏览器不会停止进程。电脑休眠、退出进程或重启电脑后不会自动执行，重新打开工作区可再次启动。界面通过真实进程与心跳展示状态，没有安装系统开机任务。

也可在项目根目录单独运行：

```bash
.venv/bin/python scripts/run_simulation_worker.py
# 外部调度场景：仅检查一次
.venv/bin/python scripts/run_simulation_worker.py --once
```

同一数据目录通过文件锁限制一个工作进程。自动执行按「账户 / 交易日 / 配置版本」去重；已经完成当天批次后，同日单纯入金不会自动再做一笔，需要手动执行或等待下一交易日。失败或条件受阻记入账户运行记录；日志位于 `data/user_profile/simulation_worker.log`。

2026 年以外的交易日历须根据交易所官方公告补充 `configs/trading_calendar_YYYY.json`。缺少日历时关闭执行，页面显示原因。
