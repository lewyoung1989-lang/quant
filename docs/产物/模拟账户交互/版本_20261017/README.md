## 直接体验

- [打开 Demo](index.html)：双击即可运行，无需安装依赖。文件需与 `app.js`、`styles.css`、`icons.js` 放在同一目录。
- 本次会话本地预览：[浏览器打开](http://127.0.0.1:8766/docs/产物/模拟账户交互/版本_20261017/index.html)。仅在本地预览服务器运行时可用。
- 本地预览服务器的重新启动方法：在项目根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，再打开上面的链接。

建议先点「体验一次调仓」，核对清单并执行；再新增账户，填写自己的策略与金额。底部「恢复初始演示」只清除本版本 Demo 在当前浏览器中的演示记录。

## 本版主要优化

| 原页面问题 | Demo 的处理 |
| --- | --- |
| 账户藏在长下拉框里，名称和策略截断 | 顶层账户列表，同时显示名称、策略、资金与待调仓状态；支持搜索 |
| 新建与管理藏在侧栏折叠项内 | 顶部「新增模拟账户」；当前账户旁直接放资金管理与设置 |
| 账户名称影响策略判断，配置容易串用 | 独立账户 ID，显式策略和参数绑定 |
| 标题过大、行情与执行主次不清 | 资产、持仓、策略观察、今日调仓形成固定层级 |
| 新增、资金、策略、执行分散 | 新增时一次选好策略与资金，账户内完成后续管理 |
| 执行按钮状态和原因难判断 | 执行清单、费用、预计剩余资金、限制原因紧邻按钮 |
| 流水与配置混在同一长页 | 五个同级标签切换，低频规则按需展开 |

## 可操作范围

- 新增账户：名称、初始金额、策略参数、手动/自动；重名、金额、阈值等就地校验。
- 策略：红利低波 ERP 择时、攻守动量轮动。更换策略保留已有持仓。
- 资金：入金、出金；不能超过可用现金；分别记录净投入与收益。
- 执行：首次建仓、先卖后买、仓位调整、费用、执行锁、成交后联动更新。
- 自动：账户开启自动后，切换尾盘情境或刷新会触发当前页面内的演示执行；暂停账户会阻止执行。
- 记录：成交、资金、配置与运行事件；成交 CSV 导出。
- 演示情境：休市、尾盘、盘中、ERP 低估、行情延迟、行情失败。
- 浏览器本地保存；桌面、平板和手机布局；标签方向键切换、表单键盘操作。

Demo 费用固定为单边万 1、无最低收费，按参考价全部模拟成交，数量按 100 份取整。其目的为验证交互；不模拟完整交易日历、标的交易限制、部分成交、滑点、真实可卖数量或真实行情时效。初始账户中的历史成交也是示例，不作为业务核验依据。

资金收益使用「当前资产 − 净投入」，展示的收益率为相对于净投入的简单比例；未实现时间加权或资金加权业绩计算。跨时点出入金后的专业业绩统计应在正式业务接入时另行实现。

情境时间是演示时钟，切换情境可以回到 2026-10-16，不能视为实际操作发生时间。不同浏览器、不同来源地址或清除浏览器数据后，本地演示记录不共享；正式持久化应交由后端。
