# 模拟账户 Demo 设计记录

适用范围：本版本独立交互 Demo，已获用户确认并作为本地 Streamlit 接入的视觉依据。正式页面现直接复用本 Demo 的 HTML/CSS 与本地图标，接入实际账户服务；初版原生控件拼接因还原度不足已替换。当前实现见[界面还原说明](界面还原说明.md)。

## 场景与方向

Operate：用户在自己的研究空间中管理多个模拟账户，日常先确认账户与资金，再看策略目标，按清单执行并复盘。

采用专业金融工作台的常规交互：浅色阅读环境、蓝色操作与选中态、中国市场红涨绿跌、对齐的表格数字。沿用原页面的中文术语与策略能力，降低标题与装饰的权重，把重要动作放到账户上下文内。

## 首屏与路径

1. 页标题与「新增模拟账户」。
2. 明确属于演示工具的情境切换条，始终在文档流中，不遮挡操作。
3. 可搜索、可横向滚动的账户卡片；同时看见名称、策略、资产和待调仓状态。
4. 当前账户标题、资金管理与账户设置；账户维度的五项资产信息。
5. 账户总览 / 成交记录 / 资金流水 / 运行记录 / 账户设置。
6. 桌面左侧持仓与策略观察，右侧调仓结论与执行清单。手机优先展示调仓结论。

## 交互承诺

- 新增账户采用单页侧边面板，基础资料、策略参数、执行方式一次完成。
- 输入错误就地提示，修改后清理过时错误；预设金额与自定义输入同步。
- 保存策略不重置持仓，下一次执行依据原持仓生成差额清单。
- 撮合先处理卖出，再处理买入；执行锁阻止重复提交，批次更新后现金、持仓、记录保持一致。
- 自动模拟仅在 Demo 打开时，由情境变更或刷新触发，界面明确披露此边界。
- 出入金同时调整净投入；收益金额不因资金划转虚增。
- 切换账户按 ID 读取配置，不以名称或序号猜测策略。

## 基础规则

背景 `#f6f7fa`，正文 `#232c3e`，次级正文 `#697386`，主操作 `#315bd6`。采用系统中文字体、固定字号、等宽数字。工作区圆角 12px，表单与按钮 6–8px，状态标签 4px；仅侧边面板与短消息使用浮层。

图标为本地保存的 Tabler outline 图标；无远程字体、CDN 或运行时依赖。动画仅用于面板、加载和执行反馈；支持减少动态效果设置。

## 状态覆盖

持仓已对齐、首次建仓、先卖后买、ERP 加仓、账户暂停、资金不足、盘中预览、休市、行情延迟、行情失败、加载中、执行中、已完成、空记录、搜索无结果及字段校验。

## 设计过程

阅读原页面截图、现有 Streamlit 和旧布局 Demo 后，按用户已给出的金融/量化平台参考建立常规工作台方向。Impeccable 的方向脚本已运行；本次以用户请求中的金融平台参考与任务完成效率为约束，没有把脚本生成的外部艺术风格用于产品操作页。

已进行一轮桌面/手机合并检查，集中修复情境浮条遮挡、输入改正后错误仍残留、零资金状态提示与新建账户情境日期；随后执行最终确认检查。机械检测器因缺少解析器使用降级扫描，不能以其空结果声称完成全面无障碍认证。
