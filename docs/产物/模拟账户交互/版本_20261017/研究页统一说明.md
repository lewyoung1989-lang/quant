# 策略研究页面统一 · 2026-10-17

针对用户反馈「点策略研究下面的菜单会跳进这些内容，风格不一致」，将红利高抛低吸、攻守轮动、因子实验、模型回测统一到已确认 Demo 的视觉体系。

## 实际改动

- 研究页与模拟账户共用同一个前端导航组件、品牌、图标与导航顺序；当前研究入口显示选中状态。可返回模拟账户，也可直接打开策略库。
- 删除旧研究页面的大段独立样式；统一蓝色主操作、背景、字号、间距、边框、指标与标签页容器，增加共享 Streamlit 主题。
- 参数从左侧导航迁到标题下方的「回测参数 · 标的、周期与交易设置」，默认折叠。桌面多列排列，手机单列；高级费率设置继续按需展开。
- 红利页红色提示改为轻量策略观察区，修正原「今日调仓」入口文案；压缩标题并移除装饰性表情。
- 平板采用图标导航与三列指标，手机提供全部研究入口与两列指标，解决标题遮挡及参数裁切。

## 使用与验证

打开 http://127.0.0.1:8501/ ，从策略研究选择页面。展开「回测参数」修改配置，再使用标题旁的运行按钮。研究回测沿用现有计算与报告流程；模拟账户的资金与交易仍走原账户服务。

已检查三个视口（1512×1100、900×1100、390×844）下全部四个研究页面：无页面异常，无整页横向溢出；各页面可展开参数，并可返回模拟账户。另验证了动量周期修改、高级设置展开及返回策略库。现有 34 项自动化测试通过。详见[验证数据](研究页统一验证.json)与[测试日志](研究页统一测试日志.txt)。

本轮没有点击重新回测或模型训练，没有产生模拟交易或改动账户资金；因此不把界面验证表述为重新验证所有策略计算。主题配置已随本地 Streamlit 服务重启加载。截图记录为本轮界面验收时状态。
